# How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Facelessism/portfolio.git
```

### 2. Navigate into the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```
http://localhost:5173
```
